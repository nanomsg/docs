Start with pynng.

pynng provides Pythonic bindings for NNG, with synchronous, asyncio, and Trio-friendly APIs. It is independently maintained, with its own maintainers and release lifecycle—not part of the NNG core project.

NNG / Cmangos / Golibnanomsg / Cnng-rs / Rustpynng / Python

The examples below are sourced from pynng’s stable master branch. Install pynng first; the async examples also need trio.

PAIRTwo-way radio for exactly two peers.PUSH / PULLOne-way work distribution.REQ / REPA client asks and a service answers.PUB / SUBTopics and broadcast to subscribers.SURVEYOR / RESPONDENTAsk many peers and collect replies.BUSA simple many-to-many mesh.

For pynng API and release questions, use the pynng documentation or its project repository; for NNG core behavior, use the NNG project.
