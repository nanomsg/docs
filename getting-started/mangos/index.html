Pure Go

Start with mangos.

mangos is a native Go implementation of the Scalability Protocols. It uses Go interfaces and errors, with protocol and transport packages selected explicitly by your application.

NNG / Cmangos / Golibnanomsg / C

The full pattern guide uses the maintained mangos v3 examples. Every pattern page includes the complete Go program and its runnable command sequence, synchronized from the mangos main branch.

PAIRTwo-way radio for exactly two peers.PUSH / PULLOne-way work distribution.REQ / REPA client asks and a service answers.PUB / SUBTopics and broadcast to subscribers.SURVEYOR / RESPONDENTAsk many peers and collect replies.BUSA simple many-to-many mesh.

Use the v3 import path: go.nanomsg.org/mangos/v3. Earlier major versions remain for existing applications but are not the path for new work.
