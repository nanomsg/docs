Start with nng-rs.

nng-rs is a safe, idiomatic Rust wrapper for NNG. It is an independently maintained project with its own maintainers and release lifecycle—not part of the NNG core project.

NNG / Cmangos / Golibnanomsg / Cnng-rs / Rustpynng / Python

The examples below are sourced from nng-rs’s default branch. Each covers one Scalability Protocol using Rust’s safe wrapper API.

PAIRTwo-way radio for exactly two peers.PUSH / PULLOne-way work distribution.REQ / REPA client asks and a service answers.PUB / SUBTopics and broadcast to subscribers.SURVEYOR / RESPONDENTAsk many peers and collect replies.BUSA simple many-to-many mesh.

For nng-rs API and release questions, use the nng-rs project; for NNG core behavior, use the NNG project.
