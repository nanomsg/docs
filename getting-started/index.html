Getting started

Choose the API that speaks your language.

The protocols are shared; the installation, lifecycle, and idioms are not. Start with the implementation you will use, then build a small PAIR application you can run locally.

Pick an implementation

These guides are maintained here so the first example tracks each implementation’s current API.

The same patterns, different APIs

The featured implementations use the Scalability Protocols. Once your two peers can exchange a message, choose the pattern that matches the shape of your system.

  • PAIRone peer to one peer
  • PUB / SUBbroadcast to interested peers
  • REQ / REPrequests and replies
  • PUSH / PULLwork distribution
  • BUSmany-to-many mesh
  • SURVEYOR / RESPONDENTcollect answers from peers
